# 要件定義書

## 概要

SwaggerからJSON形式の商品データを送信し、C#のWeb APIで受け取り、MySQLに保存する。

## 機能要件

| ID | 内容 |
|---|---|
| FR-001 | 商品データをJSON形式で登録できる |
| FR-002 | 登録済みの商品一覧を取得できる |
| FR-003 | IDを指定して商品を1件取得できる |

## 非機能要件

| ID | 内容 |
|---|---|
| NFR-001 | SwaggerからAPIを確認・実行できる |
| NFR-002 | データはMySQLに保存する |
| NFR-003 | ソースコードはGitHubで管理する |
