# 要件定義書

## 概要

SwaggerからJSON形式の商品データを送信し、C#のWeb APIで受け取り、MySQLに保存する。

## 機能要件

| ID | 内容 |
|---|---|
| FR-001 | 商品データをJSON形式で登録できる |　完了　|
| FR-002 | 登録済みの商品一覧を取得できる |　完了　|
| FR-003 | IDを指定して商品を1件取得できる |　完了　|
| FR-005 | IDを指定して商品を更新できる | 未対応 |
| FR-006 | IDを指定して商品を削除できる | 未対応 |

## 非機能要件

| ID | 内容 |
|---|---|
| NFR-001 | SwaggerからAPIを確認・実行できる |　完了　|
| NFR-002 | データはMySQLに保存する |　完了　|
| NFR-003 | ソースコードはGitHubで管理する |　完了　|

- 商品データの更新
- 商品データの削除
- READMEの整備
- エラーハンドリングの改善
